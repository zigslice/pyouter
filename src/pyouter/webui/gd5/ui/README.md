# gd5 UI

Component library for the gd5 engine. **White panels**; selectable themes: **orange** (default), **blue**, **green** (`setTheme` / `ConfigProvider`). Optional jelly material sits beside the theme: `setJelly(true)` (default off, remembered as `gd5-jelly`).

Catalog aligned with [NameThatUI](https://namethatui.com/) + Ant Design — see [`docs/ui.md`](../../docs/ui.md) and [`examples/ui-gallery.html`](../../examples/ui-gallery.html).
